MoxaSerial @VERSION@ is installed.

To turn it on in Fusion:

  1. Utilities tab → ADD-INS → Scripts and Add-Ins (or press Shift‑S)
  2. Add-Ins tab → select MoxaSerial → Run
  3. Tick Run on Startup so it loads with Fusion from now on

The buttons then appear in the Manufacture workspace: a Moxa DNC panel on the P3DTools tab, plus Send Last Program next to Post Process in the Milling and Turning action panels.

To remove it later, delete the MoxaSerial folder from ~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/.
